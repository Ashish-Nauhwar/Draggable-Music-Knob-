# 🎛️ Draggable Music Knob

A simple, lightweight web application featuring an interactive draggable wheel. As you rotate the wheel, the connected volume bar dynamically fills up with a green indicator to reflect the level.

## ✨ Features

- **Interactive Circular Wheel:** Click and drag the knob to rotate it seamlessly.
- **Dynamic Volume Indicator:** The volume bar goes green in real-time as the wheel circulates.
- **Lightweight & Fast:** Built purely with simple web technologies. No complex dependencies or frameworks required.

## 🚀 How to Run

Since this is a straightforward front-end project, you don't need to install any packages or run a local server.
